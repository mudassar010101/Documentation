WhatsApp

Connect WhatsApp so your AI agent can reply to customers who message your business on WhatsApp. There are three ways to connect. This guide explains each one.

Which option should I choose?

  • Scan QR code: The fastest way. Link your existing WhatsApp in seconds, like WhatsApp Web. Available for your trial.
  • Pairing code: No camera needed. Enter your number and type a code into WhatsApp. Available for your trial.
  • Official WhatsApp API: Meta's verified Business API. The safest option for your number, and best for long-term business use.

Step 1 — Open WhatsApp setup

Go to Channels in the sidebar and click Set up on the WhatsApp card.

Step 2 — Choose how to connect

Pick one of the three options. You can switch to a different option later.

Option A — Scan QR code

Step 1 — Scan the code with your phone

Click Scan QR code. A QR code appears on the screen.

On your phone, open WhatsApp and go to Settings → Linked devices → Link a device, then scan the code. The code refreshes by itself, so keep the page open.

Step 2 — Check that WhatsApp is connected

When the connection works, you see WhatsApp is connected and the channel shows Live.

Option B — Pairing code

Step 1 — Enter your WhatsApp number

Click Pairing code. Type your WhatsApp number with the country code, then click Get code.

Step 2 — Enter the code in WhatsApp

An 8-character code appears on the screen. On your phone, open WhatsApp and go to Settings → Linked devices → Link a device. Tap Link with phone number instead and type the code.

Step 3 — Check that WhatsApp is connected

When the connection works, you see WhatsApp is connected and the channel shows Live.

Option C — Official WhatsApp API

Click Official WhatsApp API and follow the steps below. You need a Facebook account, access to your Meta business account, and a business phone number that can receive a verification code.

Official API · Step 1 — Open the WhatsApp setup entry

Open the WhatsApp channel section in NexCognit to begin the connection flow. This is the starting point for linking your business account to the platform.

Official API · Step 2 — Connect with Facebook

Choose the option to connect the channel using Facebook. This begins the Meta-based setup needed for WhatsApp Business integration.

Official API · Step 3 — Open Facebook login

Continue through the login flow and open the Facebook sign-in step for the business account you want to use.

Official API · Step 4 — Continue the Facebook login process

Follow the Facebook login prompts until the connection flow is ready to continue.

Official API · Step 5 — Select the business page

Select the Facebook Page that will be associated with your WhatsApp Business setup.

Official API · Step 6 — Select the business ID

Choose the business account or business ID that should own the WhatsApp connection.

Official API · Step 7 — Choose the WhatsApp Business account

Select the WhatsApp Business account that will be used for customer conversations.

Official API · Step 8 — Create a WhatsApp Business account if needed

If a Business account is not already available, create one before continuing with the setup.

Official API · Step 9 — Continue account creation

Continue through the prompts to finish creating the WhatsApp Business account.

Official API · Step 10 — Choose a business category

Select the category that best describes your business so the account can be configured correctly.

Official API · Step 11 — Select the industry category

Choose the industry category that matches the nature of your business.

Official API · Step 12 — Select the other category option

If your business does not fit a common category, choose the appropriate alternative option.

Official API · Step 13 — Continue after category selection

Proceed to the next step after confirming the business category details.

Official API · Step 14 — Add a new phone number

Choose to add a phone number that will be used for the WhatsApp Business account.

Official API · Step 15 — Enter the phone number

Enter the phone number that should be associated with the WhatsApp Business account.

Official API · Step 16 — Select the country code

Choose the correct country code before continuing with number verification.

Official API · Step 17 — Open the phone number field

Open the field where the phone number is entered so the setup can continue.

Official API · Step 18 — Enter the phone number again

Complete the phone number entry and confirm that it is the intended business number.

Official API · Step 19 — Continue after phone number entry

Proceed once the phone number has been provided and verified as the correct value.

Official API · Step 20 — Open the verification code field

When prompted, open the verification code field so the number can be confirmed.

Official API · Step 21 — Enter the verification code

Enter the code sent to the phone number to verify the WhatsApp Business account.

Official API · Step 22 — Continue after verification

Continue the setup flow after the verification code has been accepted.

Official API · Step 23 — Confirm the account connection

Confirm that the account is connected and ready to be used for business messaging.

Official API · Step 24 — Finish setup

Complete the remaining setup steps so the WhatsApp Business account is fully available.

Official API · Step 25 — Enable the WhatsApp channel in NexCognit

Once the account is ready, enable the WhatsApp channel in NexCognit so it can receive incoming messages.

Official API · Step 26 — Continue configuration

Continue through the configuration screen so the connection is finalized inside NexCognit.

Official API · Step 27 — Return to NexCognit dashboard

Return to the NexCognit dashboard once the setup is complete. The WhatsApp channel is then ready to use for customer conversations.

After you connect

  • Send a test message to your WhatsApp number from another phone to check that your agent replies.
  • With Scan QR code and Pairing code, your agent replies to incoming messages only. Automated follow-ups are off for these options.
  • To stop, click Disconnect on the WhatsApp setup page.
  • All WhatsApp conversations appear in your Inbox.
